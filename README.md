
## Task 1: Java Basics & OOP Fundamentals

**Domain:** Java Developer  
**Technologies:** Java, VS Code

## Objective
To understand basic arithmetic operations and demonstrate
Object-Oriented Programming (OOP) concepts using Java.

## Program 1: Arithmetic Calculator
The program performs:
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

**File:** ArithmeticCalculator.java

## Program 2: Student Details
The program demonstrates:
- Classes and objects
- Constructors
- Methods
- Encapsulation using private fields
- The `this` keyword
- Conditional statements

**File:** StudentDemo.java

## Sample Output

### Arithmetic Calculator
For inputs 99 and 99:
- Addition: 198.0
- Subtraction: 0.0
- Multiplication: 9801.0
- Division: 1.0

### Student Details
The program displays details for two students:
- Rahul — Age 20, Course Java
- Priya — Age 17, Course Computer Science

## How to Run

Compile and run the calculator:

```bash
javac ArithmeticCalculator.java
java ArithmeticCalculator
```

Compile and run the student program:

```bash
javac StudentDemo.java
java StudentDemo
```

## Learning Outcome
Learned basic Java programming, arithmetic operations,
and fundamental OOP concepts.
