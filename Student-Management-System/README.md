
# Student Management System

A console-based Student Management System developed using Java.
This project demonstrates Object-Oriented Programming (OOP),
collections, input validation, and CRUD operations.

## Features

- Add new student records
- View all student records
- Search students by ID
- Update existing student details
- Delete student records
- Validate numeric input
- Prevent duplicate student IDs
- Display records in a formatted table

## Technologies Used

- Java
- ArrayList
- Scanner
- Visual Studio Code

## Student Information

Each student record contains:
- Student ID
- Name
- Age
- Course

## How to Run

Make sure the Java Development Kit (JDK) is installed.

Open a terminal in this project folder and run:

```bash
javac StudentManagementSystem.java
java StudentManagementSystem
```

## Menu Options

1. Add Student
2. View All Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit

## Concepts Demonstrated

- Classes and objects
- Constructors and methods
- Encapsulation
- ArrayList collection
- CRUD operations
- Loops and conditional statements
- Exception handling for numeric input

## Storage

Student records are stored in memory using an ArrayList.
Records are cleared when the application exits.
